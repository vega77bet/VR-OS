# V44 — VR-OS Design System

V44 creates the visual foundation for the frontend rebuild.

It centralizes:
- dark binocular surfaces and contrast tokens;
- typography and spacing;
- icon states backed by the supplied `VR_OS_Icons.xcassets`;
- consistent 44pt interaction targets;
- primary/secondary buttons;
- reusable surfaces and icon buttons.

The taskbar is intentionally not implemented in V44. It will consume these components in V45.

The 0.5x camera path is not part of this visual foundation and remains disabled in the rebuild branch.
